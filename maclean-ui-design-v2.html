01 · 设计原则

1. 决策优先于展示

清理工具的每一次交互都是一次"要不要删"的决策。界面必须优先回答三个问题：这是什么、多大、删了会怎样。任何不能帮助这三个问题的元素（装饰、动效、冗余分隔线）都删掉。

2. 风险可视化，而不是风险警示化

不要用弹窗轰炸用户。把风险做成常驻的、可扫读的色标（安全 / 仅缓存 / 谨慎 / 高级）与数字，危险动作只在真正不可逆时才打断。

3. 默认安全

默认勾选 = 只勾 安全 与 仅缓存；"高级"项默认不选且需二次确认；删除按钮在选中为空时禁用，不是点了才报错。

4. 一屏一任务

侧栏 9 项已经够多，主区不再塞二级导航。分类筛选用一行 pill，搜索常驻右上角，扫描结果只允许一个主列表。

5. 双端同构，各自克制

结构、栅格、组件完全一致；平台差异只体现在内容（APFS 快照只在 macOS、还原点只在 Windows），不做两套视觉语言。

6. 无 emoji

v1 的 🏠📦🧹 等 emoji 在 egui 里依赖系统 emoji 字体，Windows 与 macOS 字形、基线、宽度都不一致，会让导航条错位。全部换成 1.6px 线性 SVG 图标（第 2.5 节给出图标集）。

尺寸

小 26px 中 30px 大 36px

小尺寸用在列表行内与工具栏；大尺寸只用在弹窗主行动。

规则

  • 一屏最多 1 个实心主按钮，其余全部次级/幽灵。
  • 危险按钮必须带图标 + 明确宾语（"删除 42.7 GB"，不是"确定"）。
  • 禁用态用 #EFEFF2 底 + #AFAFB8 字，不要只降透明度。
  • 图标按钮 30×30，仅在工具栏使用。

三态复选框

分组卡片用三态：全选（勾）/ 部分选中（横杠）/ 未选。禁用项用灰底，不要隐藏复选框——要让用户看见"有东西不能选"，并在悬浮时给出原因 tooltip。

分类 pill

选中态是反色（深底白字），不是品牌色底——品牌色留给主行动按钮。pill 高度 28，圆角全圆，最多一行，超出用"更多"下拉。

3.3 徽标与状态

推荐等级徽标height 20 · radius 4 · font 11/600
安全 仅缓存 谨慎 高级 受保护 需授权 SIP 保护

不可删除项必须有可见原因徽标（受保护 / SIP / 需要完全磁盘访问权限 / 正在被使用）。静默禁用是清理工具最糟糕的做法——用户会以为软件坏了。

行内信息密度

04 · 应用框架

骨架（固定三区）

区域尺寸说明

为什么操作栏常驻

清理工具的核心动作是"勾选 → 删除"。把删除按钮放在底部常驻栏，用户随时能看到当前选中多少，避免"选了半天找不到按钮"，也避免误触。只有概览与应用卸载页自带聚合栏，其余页复用同一个组件。

响应式

≥1040px 960 宽 · 760–1040 侧栏压到 180px · <760 不允许（窗口最小 760×540）

设计要点

  • 顶部三张卡只给三个数字：能安全拿回多少、要谨慎的多少、危险的多少。这是概览存在的唯一理由。
  • 分类构成用堆叠条 + 图例列表，点击图例跳转对应 Tab。
  • "最大的 6 项"是可操作列表，不是排行榜——直接带复选框，用户在这里就能完成 80% 的清理。

egui 注意

  • 堆叠条用 painter.rect_filled 分段绘制，别用多个 Frame 拼（会有 1px 缝隙）。
  • 三张卡片用 ui.columns(3) 或 horizontal(|ui| ui.add_sized())，保证等宽。
  • 概览数据来自各 Tab 聚合（app.results[1..]），扫描未完成时显示上一次缓存值并标注时间。

为什么用分组卡片

卸载是一个对象带多个位置的结构（本体 + 偏好 + 支持文件 + 容器 + 日志）。扁平列表会让用户看到 5 行 Figma 却不知道它们是一件事。分组卡片把"应用"作为决策单位，明细折叠在里面。

分组复选框是三态；明细里某一项不可选时显示原因徽标，不静默禁用。

风险表达

  • 卡片标题右侧的等级徽标 = 该组最高风险项的等级，不是平均值。
  • "应用仍在"与"仅剩残留"必须在副标题里写清楚——这两者的用户意图完全不同。
  • 含用户数据的组（~/Documents、虚拟机）标 高级，且默认不勾选。

06 · 状态与流程

6.1 扫描状态机

Idle 未扫描→ Scanning 扫描中（进度 + 当前路径 + 可取消）→ Done 完成→ Idle（切 Tab 保留结果）
  • 扫描期间禁止切换删除按钮状态、禁止勾选——但允许切换 Tab（后台继续，回来能看到进度）。
  • 任一 Tab 正在扫描时，概览页顶部显示"正在扫描 N 个分类"，聚合数字标注为上一次结果 + 时间，不要显示半截数据。
  • 失败要可重试：扫描出错时列表区显示错误态卡片（错误原因 + 重试按钮），不要静默显示空列表。

6.2 删除流程（对应 ConfirmState）

None→ 点击清理 Pending 确认→ 确认 Deleting 删除中→ 部分失败 NeedSudoPassword→ 或 OfferTouchIdSetup → WaitForTouchIdSetup → SudoWithTouchId→ 汇总弹窗 → None
状态UI 表现必须可退出
Pending确认弹窗（列出三档分级与数量）取消 / Esc
Deleting进度弹窗 + 实时日志流（最近 5 行）后台运行（其余不提供，见下）
NeedSudoPassword密码弹窗 + 「跳过这几项」跳过 / 取消
WaitForTouchIdSetup等待弹窗 + 30s 倒计时取消（必须能回到密码方案）
汇总成功/跳过/失败三段 + 还原入口完成
当前代码的一个真实缺陷：删除线程里用了 failed_items.lock().unwrap()，任一 worker panic 会毒化 mutex 并连锁 panic；发送端被 drop 后 UI 在 Err(_) => break 处直接退出轮询，没有把 confirm 复位回 None，弹窗会卡在 Deleting 态只剩"后台运行"一条路。改法：锁用 unwrap_or_else(|e| e.into_inner())；通道 Disconnected 时强制 finish_delete()。

6.3 不可逆操作的分级

动作可逆性UI 要求
删除「安全 / 仅缓存」项系统级可重建一次确认，汇总可查
删除「谨慎」项需重新下载确认弹窗中单独成行，标明"需重新下载"
删除「高级」项需可恢复默认走废纸篓；设置项「二次确认」开启时再弹一次
卸载应用应用需重装分组卡片级确认，列出将被删除的位置
Docker system prune（不含卷）镜像需重新拉取独立确认；已移除 --volumes，清卷请引导用户到 Docker Desktop / docker volume prune（会交互式列出卷名）
删除 APFS / 时间机器快照不可逆独立确认 + 显示快照日期，默认不勾选

07 · 深色模式

深色不是把颜色取反，是重新定一套表面层级。原则：表面越靠前越亮，文字对比度不低于 4.5:1，语义色降饱和但不改色相。

背景

  • 描边在深色下要比浅色更亮才能被看见（#33333D 而非 #22222A）。
  • 浅色下用阴影表达层级，深色下改用表面亮度——深色里加阴影基本无效。
  • egui 侧：ctx.set_visuals(Visuals::dark()) 之后必须重设 widgets.noninteractive.bg_fill、selection.bg_fill，否则选中态会变成默认蓝。

08 · egui 落地要点

8.1 必改项（对照当前代码）

现状建议优先级
导航图标用 emoji（nav_icons = ["🏠","📦",…]）换成 1.6px 线性图标（内嵌 PNG 或 PathShape），否则 Windows/macOS 基线错位P0
列表行内 emoji（✓ ✗ ⟳ 🔒）换图标；日志前缀保留文本符号可接受P1
7 个 static mut 全局 + 裸 unsafe改为 impl eframe::App 持有状态，或 Mutex<T> / OnceLockP0
main.rs 8508 行混 UI / 删除 / 常量拆 ui/（overview / list / settings / modals）、ops/delete.rs、theme.rsP1
按钮高度不统一（28 / 30 / 32 混用）统一 30（小 26 / 大 36），写进 theme.rs 常量P2
颜色常量散落在 main.rs 顶部抽 theme.rs，浅/深两套 VisualsP1
概览页数字用 format_size（1 位小数）开启等宽数字（egui 需嵌入支持 tabular-nums 的字体）P2

8.2 渲染与性能

  • 空闲时用 eframe::RenderState 的响应式重绘；扫描/删除中再 ctx.request_repaint()。不要全局 RepaintMode::Continuous——清理工具可能开几小时。
  • 长列表必须 egui::ScrollArea::show_rows() 做虚拟滚动：大文件页可能有上千项，一次性 ui.label() 会掉帧。
  • 扫描结果通过 mpsc 分批回传（当前已做 send_items_in_batches，保留），每批 ≤ 50 项，避免 UI 卡顿。
  • dir_size 在后台线程算；当前 mod.rs / large_files.rs / dev_cache.rs 有三份不同实现，跳过规则不一致（一份会遍历 .photoslibrary）。统一成一份并加 rayon。

8.3 做不到的 / 别做的

别做

  • 毛玻璃 / 背景模糊 —— egui 没有，别用半透明假造。
  • 复杂补间动画 —— 立即模式里成本高，用 animate_bool 就够。
  • 自定义滚动条皮肤 —— 平台差异大，用默认。
  • 内嵌网页视图（更新日志、支付页）—— 直接 open::that(url) 打开浏览器。

要做

  • 中文字体通过 setup_fonts 显式加载，Windows 上必须指定 PingFang/Microsoft YaHei 回退。
  • 键盘：⌘R 重新扫描 · ⌘F 搜索 · Space 切换选中 · Esc 关弹窗 · ⌘1–9 切 Tab。
  • 所有容量数字用同一个 format_size，UI 不要自己再格式化一遍。
  • 配置项与 AppConfig 单一来源，别在 App 上再镜像一份 settings_* 字段（当前有 7 个，靠手工同步）。
