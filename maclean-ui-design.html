maclean UI 设计稿 v1.0

基于 egui 可实现的跨平台 macOS 风格界面方案 — 清爽、专业、可信

目标框架: egui / eframe 主色调: 紫罗兰 #4B3FE3 设计语言: macOS 原生风格 交付: 图稿 + 组件规范

1. 设计原则

当前 UI 的主要问题是信息堆叠、色彩过饱和、标签栏拥挤。新版设计遵循以下原则：

  • 信噪比优先：用白色/浅灰卡片承载内容，减少视觉噪音
  • 左导航 + 右内容：借鉴 Finder / 系统设置，左侧固定功能入口，右侧展示详情
  • 状态即颜色：Safe/Caution/Advanced 用绿/黄/红微标表达，不污染整行背景
  • 空间即层级：通过间距和阴影区分卡片，避免粗边框
  • 操作可视化：扫描、删除过程使用进度条 + 实时日志，降低焦虑

5. egui 实现要点

以下是图稿中各元素在 egui 中的可行实现方式，避免使用 egui 难以支持的效果。

5.1 布局

  • 左侧 Sidebar 使用 SidePanel::left()，固定宽度 220px
  • 右侧内容区使用 CentralPanel + ScrollArea
  • 底部 Footer 使用 TopBottomPanel::bottom()
  • 列表项使用 ui.horizontal() + 固定高度 Frame

5.2 样式

  • 圆角：通过 rounding 设置 6px / 8px / 12px
  • 边框：1px solid，颜色使用 Color32::from_gray(220)
  • 阴影：使用 egui 的 Shadow，但保持轻微（1-2px 偏移，低透明度）
  • 图标：使用系统 emoji 或加载自定义字体图标（推荐 Phosphor / SF Symbols 字体）
  • 背景：避免复杂渐变，使用纯色 + 浅灰边框

5.3 自定义绘制

  • 进度条：使用 ui.add(ProgressBar::new(...)) 并重写样式
  • 复选框：用 ui.selectable_label 或自定义 Response 绘制方框
  • 菜单栏 HUD：使用 Window::new(...) 无边框模式 + 自定义 Frame
  • 锁定状态：降低透明度、禁用 checkbox、添加 🔒 徽章

5.4 不建议在 egui 中实现的效果

  • 真正的毛玻璃 / 背景模糊（性能差且跨平台不一致）
  • 复杂的多层阴影和投影
  • 圆角窗口（依赖系统窗口管理器，eframe 支持有限）
  • 高保真动画（egui 是即时模式，复杂动画需要手动管理状态）
核心建议：新版 UI 赢在信息层级和留白，不靠特效。egui 完全能够实现上述所有设计，重点是统一颜色变量、规范间距、避免过度装饰。
