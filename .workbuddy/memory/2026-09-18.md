1. **P0 · CLI 删除零校验**（src/cli.rs:322-326）
   `cmd_clean` 只按 `item.deletable` 过滤就 `remove_dir_all` / `remove_file`，
   全程没有 `safety::check_path_safety_with_category`，也没有软链复查。

   CLI 完全缺这一层。→ Task #33

2. **P0 · Windows 两个删除出口是裸执行**
   `windows_apps.rs:3275 delete_filesystem_residual`（remove_dir_all）
   、`:3476 delete_registry_residual`（`reg delete /f`）内部都没有任何校验，
   保护全活在扫描函数里 —— 等于假设「扫的时候对 ⇒ 删的时候也对」。
   **关键坑**：X-5 的 `is_deletable_reg_path` 要求 SOFTWARE 下深度 ≥3，
   但 `scan_registry_residual` 产出的合法目标就是 SOFTWARE 下一级键
   （如 `HKCU\SOFTWARE\Zoom`）。照搬会让所有注册表残留删除失效，
   必须分两档，且改动后 Windows 上「什么能删」会变，须真机回归。→ Task #34
