## 第二轮：按 review 清单实际修复（同日）

验证状态：`cargo check` 0 error / 76 warning（全为 static mut 存量）；`cargo test --bin maclean` **75 passed 0 failed**；`cargo fmt --check` clean。

**修复内容**（均在 CODE_REVIEW.md 顶部有对照表）

- P2 `compare_versions()`（semver 预发布规则）；TM 快照 Safe→Caution；版本号统一到 Cargo.toml；`scripts/update-homebrew.sh` 回填 sha256；`notarize_app()` 公证；新增 13 个测试；新增 `.github/workflows/ci.yml`。

**关键实现坑（下次直接复用）**
- 本项目是 **binary crate**（无 lib.rs），集成测试 `tests/` 无法引用内部函数 → 单元测试只能写进源文件的 `#[cfg(test)] mod tests`，用 `cargo test --bin maclean` 跑。
- 首次 `cargo check` 约 19 分钟（egui 依赖树大），增量 3 秒；改代码前先后台起一次建立缓存。
- 本环境 bash `grep` 间歇性返回空，用 Grep 工具替代。
- `let mut x = 0usize;` 随后无条件赋值会被 clippy 判 "value assigned is never read" → 用延迟初始化 `let x: usize;`。
- `format!` 产出 String，传给 `&str` 参数要 `&script`（原来的 `r#"..."#` 是 &'static str，类型不同）。
