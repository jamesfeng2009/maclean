## 遗留三问的修复方案设计（未实现，仅方案）

产出 `FOLLOWUP_FIX_PLAN.md`，针对 CODE_REVIEW.md 的三个未决项。关键结论修正：

1. **`.env` 后门**：不用 `cfg(debug_assertions)`，改用 Cargo feature `dev-bypass` + `build.rs` 熔断
   （release + feature 同开且无 `MACLEAN_ALLOW_DEV_RELEASE=1` 直接 panic）+ DEV 角标。
   关键细节：用 `#[cfg(feature)]` 而非 `cfg!()`，让 dev 分支在正式包里根本不编译
   （`cfg!()` 会留下 `if false{...}`，`dev@maclean.app` 字符串在 LTO 下不保证被清除）。
   另发现 `main.rs:104 load_dotenv()` 读的是 CWD 的 `.env`，且 `MACLEAN_DEV` 字符串明文躺在二进制里
   → `strings` 即可发现，属收入泄漏。

2. **7 个 static mut**：**推翻上一轮"要迁 impl eframe::App"的结论**。
   `run_simple_native` 的闭包是 `FnMut`，本来就能捕获可变状态 → 直接建 `GuiState` 结构体捕获即可。
   证据：48 处引用全部落在 main.rs 265–678 的闭包体内，其余 79 个 fn 零引用 → 纯局部机械替换，
   辅助函数签名一个都不用改。预计 2h，不是结构性重构。
   `sudo_keepalive.rs:17` 单独改 `Mutex::new(None)`；`aewp.rs` 的 15 处 unsafe 是合法 FFI，保留只补 SAFETY 注释。
   顺带：`std::env::set_var` 在 edition 2024 变 unsafe，与 dev-bypass 一起处理。

3. **License 无 exp/吊销**：分三层。L1 纯离线（payload v2 加 exp + jti + 单调时钟防回滚，半天）；
   L2 签名静态吊销表 `revoked.json`（**不需要后端**，一个 ed25519 签名的静态 JSON + Cloudflare 即可，
   updater.rs 已有 curl 通路），离线宽限 30/90 天两档，一天工作量；L3 只有做订阅制才需接 Paddle。
   另建议：机器绑定硬失败改为每 90 天允许自动重绑 1 次。

## 踩坑（egui 0.29 API 实测）
- `Widgets` **没有** `disabled` 字段（0.29），禁用态只能在自定义组件里自己画。
- `Painter` **没有** `ellipse()` / `ellipse_stroke()`；要用 `Shape::Ellipse(EllipseShape{center,radius,fill,stroke})`。
- `Rect` 没有 `from_center_half_size`，用 `from_center_size(c, vec2(rx*2, ry*2))`。
- `Order::PanelResizeLayer` 不存在，遮罩 Area 用 `Order::Foreground`。
- `epaint::Shadow` 的 `offset` 是 `Vec2`，`blur/spread` 是 `f32`，别写整数字面量。
- 自定义 `Window::frame()` 会**覆盖默认 window_margin** → 必须显式给 inner_margin，否则内容贴边。
  footer 想撑满弹窗宽度要用负 `outer_margin`（-S5 / -S4）；egui 的负 Margin 可以生效。
- `Response::on_hover_text()` 是 **by value**，要 `let r = r.on_hover_text(..)` 重新绑定，否则 use-after-move。

## 深色模式 + 消 static mut + 拆分 ui/ops（已实现，79 测试通过）

### 1) 运行时换肤
`theme.rs` 升级：`Palette`（27 个 token，浅/深两版完整定义）+ `Mode` + 线程局部当前配色，
颜色从 `const` 变成**取值函数** `theme::text_2()`。全量替换 main.rs 296 处 + widgets.rs 40 处。
选型理由（写给未来的自己）：egui 是单线程立即模式，一帧一个配色，egui 自己也是全局 style；
传 `&Palette` 要改 80+ 签名，会跟「拆 ui/」的纯移动冲突。写入点只有 `set_mode` 一个，
读取默认回落浅色，不 panic。若将来要同屏多配色，改成 `Palette` 上的方法即可。
持久化：`config.AppConfig.dark_mode`；**首次启动（config.json 不存在）用
`platform::system_prefers_dark()` 取系统偏好**（macOS `defaults read -g AppleInterfaceStyle`，
Windows 注册表 `AppsUseLightTheme`）。设置页新增「外观」卡片。
新增 4 个测试：深浅两版每个 token 必须不同、WCAG 对比度（正文 4.5:1 / 辅助 3:1）。

### 2) 消除 static mut（全仓清零）
main 闭包里 7 个 → 收进 `struct Gui` + `impl eframe::App`，`run_simple_native` 换 `run_native`；
`sudo_keepalive::KEEPALIVE_STATE` → `Mutex<Option<..>>`。
保留的 unsafe：FFI（`libc::getfsstat`），合法。
注：上一轮 memory 里说「闭包能捕获可变状态所以不用 impl eframe::App」——
**实测那条路走不通**（要用 `run_native` 才拿得到 `&mut self` 的每帧回调），以本轮为准。

### 3) 拆分
`src/main.rs` 8838 → **291 行**（只留入口 + 装配 + 磁盘查询 + tests）。
`src/ui/mod.rs`（6047 行，面板/行/弹窗/HUD/Gui）、`src/ops/mod.rs`（2536 行，扫描/删除/sudo/TouchID/优化执行）。
ops 不依赖 ui，单向依赖。搬运用脚本按「顶层条目装饰块起点」切分 + 拼接断言，保证零行丢失。

## 严重事故与恢复（务必记住）
用 Python 重写 main.rs 时写了 `lines[:start] + [新内容]`，**忘了拼 `lines[end+2:]`，
main.rs 被截断成 563 行，上一轮未提交的 UI 改动（~8000 行）全丢**。git 里只有上一轮之前的版本。
恢复路径（有效）：`~/.workbuddy/changes-detail/<conv>/cd_*.json` 存着每次编辑的
**相对 HEAD 的累积 unified diff**（`files[].hunks[].lines`，上下文行带一个前导空格）。
按 createdAt 排序后依次应用到 `git show HEAD:src/main.rs` 上即可还原：
链 A（50 hunk）→ 8954 行，链 B（53 hunk）→ 8753 行，补回 1 行 diff 掉的行 = 8754，完全对上。
**教训**：任何「切片重写整个文件」的脚本，必须 (a) 写盘前断言行数合理、(b) 先 `cp` 备份。

## 环境备注
- macOS 自带 BSD grep **不支持 BRE 的 `\|`**，多模式匹配必须用 `grep -E`。踩过两次，记牢。
- 用 Python 解析 Rust 源码做批量替换时，必须处理：**字符字面量 `'\''`**（否则会当成字符串开头
  吞掉整段代码）、**raw string `r"..."`**（找闭合引号要从 `j+2` 开始，不是 `j+1`）、
  **生命周期 `'a`**（不是字符字面量，只吃一个字符）。这三点各坑过一次。
- 拆分后各模块要同时 `use crate::scanner;` 和 `use crate::scanner::{...}`：
  前者给 `scanner::Foo` 这种路径用，后者给裸名字用，缺一个就报 E0433。
- 统计符号引用分布时，用 Python 按「最近前置 fn 定义」归因，能快速证明改动是否局部。
- 批量改 main.rs（8900 行）时：**并行发两个 Edit 到同一文件会互相覆盖**，必须串行；
  大段替换用 Python 按行号切最稳。正则批量替换 `format!("{}", X)` 类改动极易误伤
  （把 `.to_string()` 插进 `app.t("key")` 的括号里），改完必须立刻编译验证。
- 本仓 `cargo run` 需显式 `--bin maclean`（还有 maclean-keygen 这个 bin）。
