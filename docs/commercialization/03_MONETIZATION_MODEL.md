# 03 Monetization Model

## Principle
Do not charge for knowing that the disk is full. Charge for safely acting on that knowledge and continuously managing it.

## Free
- full storage scan
- developer storage inventory
- project discovery
- reclaimable estimate
- growth snapshot
- limited history
- read-only JSON export

## Pro
- cleanup execution
- restore workflow
- smart cleanup policies
- scheduled automation
- full history
- storage forecast
- advanced project intelligence
- CLI Pro automation features
- premium rules
- local AI explanation layer

## Team — future
- device enrollment
- centralized policy
- fleet storage dashboard
- aggregate reclaimable storage
- audit logs
- team policies
- SSO later

## Recommended launch pricing

### Founder
$19.99 one-time
- 1 Mac
- all V1 Pro features
- lifetime V1 updates
- limited-time founding offer

### Personal Pro
$29.99 one-time
- up to 3 Macs
- V1.x updates
- automation
- CLI
- storage history

### Team
Target $5/device/month, minimum 5 seats.
Do not launch until desktop retention and usage prove recurring value.

## Conversion model

Free:
Scan → Explain → Show reclaimable GB → Show growth → gated Cleanup

Paywall trigger:
User has selected >= one actionable cleanup item and sees a quantified reclaimable amount.

Avoid:
- blocking the initial scan
- fake scare alerts
- deleting after trial expiry
- dark-pattern countdowns

## Revenue funnel

Traffic
→ free scan
→ developer storage report
→ reclaimable insight
→ cleanup intent
→ Pro
→ multi-Mac
→ Team

## Key metrics
- visitor → download
- download → first scan
- scan → actionable finding
- finding → cleanup attempt
- cleanup attempt → purchase
- 30-day repeat scan
- 90-day retention
- refund rate
- support tickets per 1k users
