# 16 Go-To-Market Plan

## Phase 1 — Validation
Goal: prove developers understand the new category.

Channels:
- GitHub
- Hacker News
- Reddit developer communities where promotion is permitted
- X/Bluesky developer audience
- Product Hunt
- indie developer communities

Content:
1. “Why my Mac developer storage grew by 100GB”
2. “What is actually inside System Data on a developer Mac?”
3. “How much storage do AI coding tools consume?”
4. “A safe model for cleaning node_modules and build artifacts”

## Phase 2 — Founder launch
Offer:
- $19.99 founding lifetime
- limited by time, not fake inventory

Goal:
- 100 paid users
- 1,000 installs
- 30% weekly active scan among installers

## Phase 3 — Product proof
Publish anonymized aggregate insights only with consent:
- median developer storage
- top growth categories
- reclaimable percentage

## Distribution loop

```text
Technical article
 → free scanner
 → storage report
 → shareable report
 → GitHub/star
 → Pro
```

## Viral artifact
Generate a local share card:
> “maclean found 83.4 GB of reclaimable developer storage.”

Never expose paths or personal data.

## Partnerships
Potential:
- developer newsletters
- Mac developer communities
- AI coding newsletters
- indie hacker communities

## KPIs
Activation:
- download → scan > 60%
Insight:
- scan → actionable result > 70%
Conversion:
- actionable result → paid target 5–12% initially
Retention:
- 30-day rescan > 25%

These are targets, not guarantees.
