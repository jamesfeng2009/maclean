# 01 Product Positioning

## Product
**maclean — Developer Storage Intelligence & Automation**

## Positioning statement
For developers using macOS who regularly lose disk space to builds, caches, package stores, containers and local AI assets, maclean is a local-first storage intelligence tool that explains developer storage, identifies reclaimable data, safely cleans it and automates future cleanup.

Unlike generic Mac cleaners and developer-only cleanup apps, maclean manages the **lifecycle of developer storage**, not just the deletion event.

## Brand promise
> Know what is using your disk. Know what you can safely reclaim.

## UX principle
Every destructive action must answer:
- What?
- Why?
- How much?
- What happens after deletion?
- Can it be restored?
- Is it currently in use?

## Success definition
maclean is successful when users stop thinking of it as “a cleaner” and start using it as their developer storage control plane.
