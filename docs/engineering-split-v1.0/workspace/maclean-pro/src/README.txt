PRIVATE REPOSITORY SKELETON

- maclean-pro-intelligence
- maclean-pro-history
- maclean-pro-forecast
- maclean-pro-policy
- maclean-pro-automation
- maclean-pro-ai
- maclean-pro-entitlement
